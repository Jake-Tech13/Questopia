Questopia est un projet personnel codé en python et fonctionnant via la console Windows.
Fortement inspiré du jeu "Miitopia", Questopia rassemble les mécaniques clés des jeux de combats style fantaisie en tour-à-tour, avec mon petit grain de sel en plus :p

Le premier commit est là pour initialiser le projet sur Github, pour le moment le jeu n'est pas encore jouable mais point d'inquiétude, j'y travaille un peu tous les jours !
Le temps que les premières mécaniques soient implémentées et que la logique soit structurée, je pourrais ensuite commencer à release les builds sur lesquels je travaille.

Je doute que quiconque lise ça mais si le projet vous intéresse, n'hésitez pas à suivre ce repo, et merci d'avance !

Allez je dois y retourner moi. A + dans le cactus ;P
